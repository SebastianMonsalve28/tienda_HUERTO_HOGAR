# HuertoHogar

Proyecto web desarrollado para la asignatura **Desarrollo Fullstack II - DSY1104**.

HuertoHogar corresponde a una tienda online dedicada a ofrecer productos frescos y naturales directamente del campo a los clientes.

## Integrantes

- Sebastian Monsalve
- Lucas Parra

## Descripción del proyecto

El proyecto consiste en el desarrollo de una tienda online utilizando HTML5, CSS y JavaScript.

La página permite navegar entre distintas secciones de HuertoHogar, visualizar productos, revisar información de cada producto, utilizar un carrito de compras y acceder a diferentes formularios.

También se incluye una vista administrativa para organizar productos y usuarios.

## Tecnologías utilizadas

- HTML5
- CSS
- JavaScript
- Git
- GitHub
- Visual Studio Code
- Live Server
